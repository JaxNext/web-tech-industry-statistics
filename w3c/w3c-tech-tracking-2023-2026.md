# W3资讯 × W3C Web 技术演进（2023-11 – 2026-11）

对微信公众号 **W3资讯** 近三年 137 篇文章的逐篇抽取结果：哪些 Web 技术被新增或更新、走到了哪个标准化阶段。

**数据来源**：`w3-info-articles-2023-2026.md`（同目录）所列 137 篇原文全文，逐篇抓取正文后结构化。
**口径**：以 W3C 官方阶段命名为准 —— 首个公开工作草案（FPWD）→ 工作草案（WD）→ 候选推荐（CR）→ 提案推荐（PR）→ 推荐标准（REC）；小组备忘（NOTE）与“新增/纳入章程”单列，不计入成熟度。

**两个必读局限**：

1. **专辑收录不全。** 2025-06 至 2025-09 等月份在公众号专辑中无条目，下表的时间分布反映的是“被收录的文章”，不是 W3C 的全部动作。
2. **报道滞后于规范。** 一篇文章只记录它发布那一刻的状态；某项技术后来升级，若公众号未再报道，表中仍显示旧阶段。表中「最近报道」是文章日期，不是规范的真实更新日期。

## 四、观察

**1. CSS 是最高产的规范线。** 21 项 FPWD 中有 9 项是 CSS 模块：间隙装饰、表单控件样式、颜色 HDR、缓动函数 L2、滚动吸附 L2、视口、链接参数、函数与混入、背景 L4，另有指针驱动动画。方向很一致 —— 把布局、排版、动效里长期靠 hack 或 JS 解决的问题逐个标准化（间隙装饰对应 `column-rule` 的推广、函数与混入对应 Sass、链接参数对应设计令牌）。

**2. 2025–2026 的主线是 Agentic Web，而不是新的渲染能力。** 60 个技术主题里超过三分之一与智能体或 AI 相关，且已经从“讨论”走到“社区组/标准化探索”：生成式 UI 社区组、WebSkill、MCP 服务、意图驱动 Web、面向智能体的站点设计。这与同期 Chrome 的 WebMCP、Modern Web Guidance 是同一条线。

**3. 数字身份是第二条长线，且正在从 DID 转向“凭证 + 智能体身份”。** 2024 年集中发布 4 份 DID 小组备忘、DID Resolution FPWD；2025 年把 Digital Credentials 纳入联合身份工作组章程、给受控标识符加 SM2；2026 年出现基于 DID 的智能体通讯方案 AWiki。

**4. 隐私与安全没有降温。** GPC 进入 FPWD、TAG 明确要求消除第三方 cookies、XSS/JS realms/cookies 安全模型的专题持续出现，2026 年还叠加了 C2PA 这类 AI 内容凭证议题。

**5. 平台边界在向外扩。** WinterTC 把标准化推进到服务端运行时，云边端协同讨论计算卸载的 API，Web Install API、MiniApp Addressing、Open Screen、WebXR 人体追踪则分别向安装、小程序、跨屏、人体输入扩张 —— Web 平台不再只是“页面”。

**6. 报道密度不等于规范活跃度。** 2024 年收录 70 篇、2026 年收录 34 篇，但 2026 年的条目几乎全部来自 AI 专辑。更合理的解读是**公众号的编辑重心转向了 AI**，而不是 W3C 停止了 CSS 与平台工作 —— 事实上 2026 年仍有 CSS 链接参数、指针驱动动画两个 FPWD。
